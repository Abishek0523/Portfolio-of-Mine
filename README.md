# Abishek — Personal Portfolio

A responsive developer portfolio built with plain HTML, CSS and JavaScript.

## Folder structure

- `index.html` — main page
- `css/style.css` — design and responsive styles
- `js/script.js` — navigation, reveal animations and active section
- `assets/` — place your profile photo and project images here

## Before publishing

1. Replace `YOUR PHOTO` in `index.html` with your actual profile image.
2. Replace the GitHub and LinkedIn URLs with your profiles.
3. Replace `your.email@example.com` with your email.
4. Add real GitHub/live-demo URLs to project cards.
5. Add project screenshots to `assets/` if desired.

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy

This static site can be deployed on GitHub Pages, Netlify, Vercel, or any normal web host.
